# 📈 Stock Market Analysis & Prediction

A machine learning project focused on analyzing stock market data and predicting stock price trends using multiple machine learning and deep learning models.

## 🚀 Project Overview

This project explores different machine learning approaches for stock market prediction and compares their performance.

## 🧠 Models Used

- LSTM
- Random Forest
- Linear Regression

## 🛠️ Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- TensorFlow
- Keras
- Jupyter Notebook
- Anaconda

## 🔍 What I Worked On

- Processed and cleaned stock market data
- Performed data analysis and visualization
- Built and trained multiple prediction models
- Compared model performance
- Analyzed stock price trends

## 📊 Project Workflow

Data Collection → Data Preprocessing → Exploratory Data Analysis → Model Training → Prediction → Model Comparison
